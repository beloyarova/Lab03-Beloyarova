ПР3. Ответы на контрольные вопросы

1. Чем x += 5; отличается от x = x + 5;? Есть ли разница в результате?

Отличается краткостью записи. Разницы никакой нет

2. В чём разница между x++ и ++x, если результат сразу используется в выражении (например, передаётся в Console.WriteLine)?

x++ возвращает текущее значение затем увеличивает на 1

x++ сначала увеличивает на 1 потом возвращает новое значение

3. Какой тип данных всегда получается в результате оператора сравнения (==, <, >= и т.д.)?

bool

4. Что такое «короткое замыкание» в && и ||? Приведите свой пример, где это имеет практическое значение.

Короткое замыкание механизм оптимизации при котором C# прекращает вычисление как только итоговый результат становится очевидным

При && если первое условие ложно то второе не проверяется

При || если первое условие истинно то второе не проверяется

5. Расставьте приоритет для выражения 10 - 2 * 3 + 4 / 2, посчитайте вручную, а затем проверьте кодом

Сначала умножение и деление:

2 * 3 = 6

4 / 2 = 2

Получаем

10 - 6 + 2 = 6

6. Почему хорошим тоном считается расставлять скобки даже там, где они не обязательны по приоритету операций?

Скобки делают чтение кода более легким для человека который видит код впервые. Благодаря этому программа становится понятней
